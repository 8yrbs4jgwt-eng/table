# Table

iOS-приложение (SwiftUI, iOS 17+): показатели из «Здоровья», календарь со своими событиями и расписание СПбГУ (Высшая школа менеджмента).

## Сайт

В `docs/index.html` лежит веб-версия без сервера и сборки: календарь, свои события и расписание группы. Данные хранятся в браузере. «Здоровье» из браузера недоступно, поэтому шаги на сайте вводятся вручную.

Чтобы открыть её по ссылке: Settings → Pages → Deploy from a branch → выбрать ветку и папку `/docs`. На iPhone страницу можно добавить на экран «Домой» через «Поделиться».

## Что умеет приложение

- **Сегодня** — шаги с кольцом прогресса к цели, ближайшая пара, расписание и события на день.
- **Календарь** — месячная сетка; занятия из расписания (синяя точка) и свои события (оранжевая). Для каждой пары: время, предмет, вид занятия, адрес и аудитория, преподаватель, отметка об отмене. Свои события можно добавлять, редактировать и удалять.
- **Здоровье** — шаги, дистанция, активные калории, этажи, минуты упражнений, пульс, пульс в покое, вариабельность пульса, кислород в крови, сон, вес, вода; график шагов за неделю. Набор показателей выбирается.
- **Настройки** — выбор уровня → направления → года поступления → группы, цель по шагам, показатели.

Расписание берётся из открытого API `https://timetable.spbu.ru/api/v1` (подразделение `GSOM`) и кэшируется на устройстве. Данные «Здоровья» только читаются и никуда не отправляются.

## Как запустить на iPhone

Нужен Mac с Xcode 16 или новее.

1. Откройте `Table.xcodeproj`.
2. Цель **Table** → **Signing & Capabilities**: выберите свою команду (подойдёт бесплатный Apple ID) и замените Bundle Identifier `com.tableapp.Table` на уникальный.
3. Подключите iPhone, выберите его как устройство запуска и нажмите **Run**.
4. В приложении: «Подключить „Здоровье“» и «Настройки → Выбрать направление и группу».

В симуляторе «Здоровье» работает, но данных там нет — их можно добавить вручную в приложении «Здоровье» симулятора.

## Структура

- `Table/Models` — модели расписания и событий.
- `Table/Services` — `TimetableAPI`, `TimetableStore` (кэш по месяцам), `EventStore`, `HealthManager` (HealthKit).
- `Table/Views` — экраны.
