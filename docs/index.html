Шаги

Шаги из «Здоровья» на iPhone

Сайт сам читать «Здоровье» не может, но шаги может передавать приложение «Команды». Настраивается один раз:

  1. Откройте «Команды» → «+» и добавьте действие «Найти образцы здоровья»: тип — «Шаги», фильтр «Дата начала — сегодня».
  2. Добавьте «Рассчитать статистику» — «Сумма».
  3. Добавьте «Открыть URL»: вставьте ссылку ниже и сразу после неё поставьте переменную «Результат статистики».
  4. Назовите команду «Шаги» и запустите — сайт откроется уже с шагами.

Чтобы шаги обновлялись сами: «Команды» → «Автоматизация» → например, «Время суток» → запускать команду «Шаги». Дистанцию и калории можно передать так же, дописав к ссылке &km= и &kcal=.

События, шаги и выбранная группа хранятся только в этом браузере.
